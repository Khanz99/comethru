# Comethru

Comethru is an anonymous real-time social platform built around wall posts, comments, likes, notifications, and private chat.

The app explores how anonymous social interaction can be made more personal, mobile-friendly, and community-focused.

- Supabase
- Supabase Auth
- Supabase Realtime

## Features

- Anonymous wall posts
- Post detail pages
- Comments
- Likes
- Private chat requests
- Real-time messaging
- Typing indicators
- Seen status
- Notifications
- Mobile-responsive UI
- Supabase authentication

## Project Purpose

Comethru was created as a product-style full-stack project to explore real-time communication, anonymous posting, social interaction design, and modern web application architecture.

The long-term idea is to position it as a campus/community-based anonymous social platform where users can share thoughts, start conversations, and interact through private chat.
